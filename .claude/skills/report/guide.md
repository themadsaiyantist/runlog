# The two lines you write

**Summary.** One sentence: the number of runs, the best run with its model and accuracy, and the one thing that stands out most. Something stands out when a model's mean accuracy is far below the others, when the top runs are all one model, or when the tests fail or the log has errors.

**Next.** One suggestion for the next run: a model, a learning rate and a number of epochs, and the reason in the same sentence. Base it only on the numbers in this report. Never suggest a model that is not in the report.

Write both in plain words, with numbers as the report prints them.
